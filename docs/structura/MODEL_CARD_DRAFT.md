# Structura FLAN-T5 Small

## Model Description

Structura is a compact fine-tuned model for converting a user query and retrieved RAG context into validated business JSON for e-commerce, support and CRM automation.

## Intended Use

Use this model as a structured decision layer after retrieval:

```text
user_query + retrieved_context -> StructuraOutput JSON
```

The output can be passed to product filters, CRM actions, support routing or a separate answer generator.

## Input Format

The training prompt contains:

- task instruction
- user query
- compact JSON retrieved context
- `Output JSON` marker

## Output Schema

See `src/structura/schemas.py`.

## Training Data

Initial data is synthetic and generated by:

- `scripts/structura/generate_catalog.py`
- `scripts/structura/generate_dataset.py`

Default smoke dataset size: 1,000 examples.

## Limitations

- The first dataset is synthetic and should not be treated as a real business benchmark.
- The model is trained for structured output, not natural-language support answers.
- Product ids must be grounded in retrieved context; downstream code should still validate grounding.
- Prompt injection coverage is synthetic and should be extended with manual adversarial cases.

## Safety Notes

Always run JSON parsing, Pydantic validation and grounding validation before taking business actions from model output.
